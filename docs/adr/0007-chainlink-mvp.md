# ADR 0007: Chainlink MVP 用例

- **状态**：草案（基于 OQ-007）
- **日期**：2026-08-08

## 决策

- **MVP 不接入 Chainlink**。
- 理由：
  - 课程完成判定走平台事件（ADR 0006）。
  - 价格展示可前端静态 + 后端缓存，不需链上预言机。
  - SLA / fallback / cost 不明，引入会增加攻击面。

## 后续触发条件

- 必须出现至少一项**不可替代**用例：
  - 跨链价格锚定（稳定币入金）；
  - 自动化 treasury 操作（rebalance / 收益）；
  - 外部证书签发（院校证明）。
- 任一触发后再开 ADR 重启评审。
