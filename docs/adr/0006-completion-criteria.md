# ADR 0006: 完课规则

- **状态**：草案（基于 OQ-006）
- **日期**：2026-08-08

## 决策（MVP）

- **平台事件为唯一可信来源**：服务端按必修课时完成度（≥ 阈值）判定。
- 规则存 `course_versions.completion_rule` JSONB，version 化。
- 预留扩展点（OQ-006 后续可叠加）：考试、老师审核、外部证明 — **不替代**平台事件。

## 风险

- 完课被服务端状态控制，老师/学生无法用考试补充。
- 后续接入 Oracle/Chainlink 时需确保"考试通过"只是额外证据，不绕过平台判定。
